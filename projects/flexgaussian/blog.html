FlexGaussian: Flexible and Cost-Effective Training-Free Compression for 3D Gaussian Splatting

Boyuan Tian, Qizhe Gao, Siran Xianyu, Xiaotong Cui, Minjia Zhang

Blog: Training-Free Compression That Scales

3D Gaussian Splatting (3DGS) has rapidly become the de facto candidate for representing 3D scenes. It strikes a rare balance—offering both exceptional visual quality and real-time rendering speeds. But it comes at the cost of massive file sizes.

Compressing 3DGS is essential. While prior work uses pruning, quantization, or compact data structures, most methods require retraining—making them slow and impractical.

Can We Compress Without Training?

Yes. Inspired by zero-shot LLM compression, we explore training-free 3DGS compression. The key insight: attribute sensitivity varies widely, and we can exploit this to prune and quantize wisely—without retraining.

Introducing FlexGaussian

  • Pruning: Remove less important Gaussians using importance scores
  • Quantization: Apply different bit-widths per attribute based on visual impact

We evaluate (P_row, P_sh) pruning parameters and quantize attributes to 4/8/16 bits. Some (e.g. SH colors) tolerate low bits; others (e.g. positions) do not.

Pipeline

  1. Compute importance scores
  2. Prune using (P_row, P_sh)
  3. Quantize attributes
  4. Render and evaluate PSNR

This loop takes 1–2 seconds. No retraining. No overhead. Just fast, adaptive compression.

Results

  • Up to 96.4% compression
  • < 1 dB PSNR drop
  • 1.7–2.1× faster than FCGS
  • Efficient on Jetson Xavier

FlexGaussian is a powerful, training-free method that enables 3DGS streaming and deployment on edge devices.
