VecFlow

A GPU vector data management system for large-scale and high‑performance vector search.

VecFlow is a line of work on vector search on GPUs. Currently it has two parts. Filtered Search accelerates approximate nearest neighbor search. Multi-Vector Search targets ColBERT-style token embeddings, scoring a query and a document as sets of token vectors with Chamfer (MaxSim) similarity. Both co-design the algorithm with GPU and modern superchip architectures.
