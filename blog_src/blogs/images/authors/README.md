# Author Avatars

This directory contains avatar images for blog authors.

## File Naming Convention

- `ssail-avatar.jpg` - For author "ssail"
- `s_bekman-avatar.jpg` - For author "s_bekman"
- `s_rajbhandari-avatar.jpg` - For author "s_rajbhandari"

## Image Requirements

- Format: JPG or PNG
- Size: 200x200 pixels minimum (will be resized automatically)
- Style: Professional headshot or avatar
- Background: Clean, professional background

## Placeholder Images

If no avatar image is provided, the system will automatically generate a placeholder with the author's initials.
